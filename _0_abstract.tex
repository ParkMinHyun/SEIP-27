\begin{abstract}
% We present the Budget-Aware Draft Controller, which enables lightweight multi-frame composition in the initial-image pipeline of Samsung Galaxy cameras under parallel capture and a fixed per-capture deadline.
% Under parallel capture, initial-image processing shares a serialized worker, so work admitted for one capture can consume the deadline budget of subsequent captures.
% The production system limits this risk with a fixed thermal cutoff, which does not account for the live deadline state of individual captures.
% Our controller coordinates remaining-sequence admission with capture-availability pacing using observed processing durations.
% We evaluate the controller across 28 combinations of two devices, two capture conditions, and seven starting overheat levels.
% Every controller run completed 30 captures without an observed deadline violation, whereas the unguarded baseline reached Capture Timeout in 26 of the 28 cells.
% The controller also continued to execute lightweight multi-frame composition at or above the thermal cutoff.
% These results show that coordinated admission and pacing can enable lightweight multi-frame composition in the initial-image pipeline without relying on static feature suppression under per-capture deadlines.
\end{abstract}
