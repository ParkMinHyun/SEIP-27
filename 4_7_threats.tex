\subsection{Threats to Validity}
\label{sec:threats}

\smallskip\noindent\textbf{Cold start.}
Both components rely on observed draft sequence durations, so the controller has no prior timing evidence before the first sequence completes.
If that sequence runs unusually long while parallel captures continue to arrive, the resulting queue cannot yet be reflected in either decision, and the bottleneck must be handled by the underlying image solution.
We implemented warm-up data support but left it disabled: no cold-start timeout was observed, and maintaining the dataset would add storage and maintenance cost.

\smallskip\noindent\textbf{Mandatory-stage stalls.}
Encoding and saving are mandatory and cannot be skipped by admission.
Persistent slowdowns are reflected in subsequent duration estimates, allowing both admission and pacing to respond.
An isolated spike is not, because it is absent from the history available before it occurs, and the watchdog protects only the admitted optional stage.
No isolated mandatory-stage stall was observed in our evaluation; deferring non-critical saving work through a deadline-aware fast path could further reduce this exposure.
When one occurs in production, the source of the latency in encoding, database transactions, or file writing must be diagnosed directly.
