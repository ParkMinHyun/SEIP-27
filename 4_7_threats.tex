\subsection{Threats to Validity}
\label{sec:threats}

\smallskip\noindent\textbf{Cold start.}
Both components rely on observed draft sequence durations, so the controller has no prior timing evidence before the first sequence completes.
If that sequence runs unusually long while parallel captures continue to arrive, the resulting queue cannot yet be reflected in either decision.
This cold-start bottleneck must therefore be addressed by the underlying image solution or by warm-up data.
We implemented warm-up data support, but left it disabled because no cold-start timeout was observed and maintaining the dataset would add storage and maintenance cost.

\smallskip\noindent\textbf{Mandatory-stage stalls.}
Encoding and saving are mandatory stages that admission cannot skip.
When their slowdown persists across captures, the longer durations are incorporated into subsequent estimates, allowing both admission and pacing to adapt.
However, a sudden stall cannot be reflected in the estimate because it is absent from the history available at the decision point, and the watchdog covers only the admitted optional stage.
Encoding and saving are less CPU-intensive than optional image processing, and we observed no isolated stall during evaluation.
We therefore did not add a safeguard for this path.
If needed, the mandatory path could be made more robust by preparing file and database resources earlier, deferring non-critical saving work, and bounding database waits.
