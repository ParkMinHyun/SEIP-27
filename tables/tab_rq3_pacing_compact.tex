%
% NOT YET WRITTEN: Section~\ref{sec:experiments} has no RQ3 prose, so the claim
% limits below currently appear nowhere a reader sees them.  They must be in body
% text before submission.  The three that cannot be dropped are marked LIMIT.
%
% Definitions
%   B          measured Draft backlog at the pacing decision
%   T          remaining deadline window at the decision
%   C_exec     realized duration of the admitted Draft sequence
%   C_mand     DynamicFunction, Encoding and measured Draft overhead, i.e.
%              C_exec with the admission-skippable optional work removed
%   d          the applied pacing delay
%   d*_exec    ceil( [B + 2*C_exec - max(0,T)]^+ / 2 )
%   d*_mand    the same on C_mand
%   retrospective pressure  B + 2C - max(0,T); projected overrun is nonnegative
%              pressure, NOT an observed Capture Timeout
%   demotion   a reduction from Bokeh+Filter to Filter-only or Encoding-only
%   spare      retrospective pressure negated, as a share of the budget
%
% The 2C horizon is the deployed prospective model: (i) the Draft that begins
% after the pacing decision and (ii) the Draft of the next capture released by
% that delay.  Waiting one millisecond both drains one millisecond of backlog and
% shifts the next deadline by one millisecond, hence the division by two.
%
% Derived quantities
%   delay avoided     d*_exec - d within the flexible band.  LIMIT: this is not a
%                     counterfactual end-to-end speedup.  Pacing is closed-loop,
%                     so a smaller delay would have changed later arrivals,
%                     backlog, admission and thermal state.
%   backlog overlap   sum(min(d,B)) / sum(d) over paced transitions
%   burst cost        sum(d) divided by the sum of shot-to-shot intervals
%   P50 / P95         inclusive percentiles
%
% LIMIT -- target-or-next.  The flexible-band demotion row reports whether
% admission demoted the target Draft or the next capture's Draft, which is the
% same two-Draft horizon the delay is sized against.  It is an observed-action
% audit over that horizon and must never be phrased as causal attribution of the
% next admission decision to the current delay.
%
% LIMIT -- the mandatory floor.  d*_mand is a retrospective sufficient
% reservation condition, not the timeout boundary.  All 14 floor misses had their
% target demoted, but because d*_mand already excludes optional work, demotion
% documents coordination rather than erasing the deficit.  The 14 cluster in four
% 24MP bursts, retained at least 307 ms (target) and 276 ms (next) of realized
% margin, and none produced an actual Capture Timeout.  Backlog under-estimation
% in 14/14 and rising headroom in 12/14 over a median 4.78 s of queue residence
% are observationally consistent with queue and thermal drift after the online
% decision; do not claim causality from this trace split.
%
% Population.  Records affected by the known timeout-measurement error were
% removed as invalid observations, which is data-quality filtering and NOT
% outcome-based survival conditioning; no valid analyzed run experienced an actual
% Capture Timeout, and the manuscript must not describe this population as
% survival-conditioned.  Watchdog-truncated transitions lack a complete realized
% Draft duration and are excluded from envelope reconstruction only.  Complete
% 30-shot runs from data/ablation_sampling/48U_metrics_{12MP_normal,24MP_memory}_0803_{1,2}.xlsx:
% 70 and 69 bursts, 1,920 and 1,861 analyzed transitions.
%
% Regenerate with scripts/rq3_policy_metrics.py, scripts/rq3_coordination_metrics.py
% and scripts/rq3_coordination_audit.py; see docs/rq3-current.md for the order.
