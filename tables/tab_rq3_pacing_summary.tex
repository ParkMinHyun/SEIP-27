% RQ3: trace-conditioned calibration of the deployed pacing decision.
%
% Implementation source: private ML repository commit
% 99aae0af8c3fa1ceb784083446e83c40d0fb917f (2026-08-04).
% Workbooks (implementation-repository relative):
%   data/0803_FULL/SM-S948U_metrics_12MP_normal_0803.xlsx
%   data/0803_FULL/SM-S948U_metrics_24MP_memory_0803.xlsx
%
% Inclusion protocol:
%   - first 30 shots of a complete run;
%   - no Capture Timeout or watchdog failure anywhere in the run;
%   - a recorded pacing decision, complete reconstructed pre-delay backlog,
%     remaining-deadline sample, and measured Draft duration;
%   - all planned/executed configurations retained.  Removing changed
%     configurations would discard 529/1167 normal and 477/1013 memory-pressure
%     decisions, selecting away the states in which Admission coordinated with
%     pacing.
% For the 24MP-mode workbook, Lv0--4 runs begin with two MP24 captures and then
% use MP12; Lv5--6 use the production MP12 fallback.  The isolated all-MP12
% starting-Lv3 run is not a 24MP-mode run and is excluded.  Every calculation
% uses the per-capture executed size/duration rather than the run's first-size
% bucket.
%
% The controller's shared-deficit equation is re-evaluated with measured
% quantities, not a fixed 300-ms reserve:
%   d_trace = ceil(max(0, B_real + 2 C_exec - T) / 2).
% The safety floor substitutes the measured mandatory duration for C_exec.
% Mandatory duration is DynamicFunction + required Frame Watermark (if any) +
% Encoding + measured non-node Draft overhead.  draftEndUptimeMs is recorded
% after Encoding completion and timeout evaluation but before database insert,
% so database time is correctly outside this deadline measure.
%
% Unrounded aggregate values are in data/rq3/calibration/summary.csv; the run
% inclusion audit is in data/rq3/calibration/run_audit.csv.

  {\scriptsize For decision \(i\), the executed-work target is
  \(d_i^{\mathrm{tr}}=\lceil[B_i^{\mathrm{real}}+2C_i^{\mathrm{exec}}-T_i]_+/2\rceil\),
  obtained by substituting measured pre-delay backlog, executed Draft duration,
  and remaining deadline into the deployed two-Draft shared-deficit equation.
  The safety-floor target substitutes measured mandatory work for
  \(C_i^{\mathrm{exec}}\). ``Covered'' means \(d_i\ge d_i^{\mathrm{tr}}\), and
  \(e_i=d_i-d_i^{\mathrm{tr}}\); negative errors are insufficient for the
  executed sequence and positive errors are conservative. Zero target when
  paced is \(\Pr(d_i^{\mathrm{tr}}=0\mid d_i>0)\). Cumulative excess is the
  run-level median of \(\sum_i e_i^+\) and therefore does not duplicate RQ1's
  cumulative applied delay. The target is local and trace-conditioned: it
  audits the deployed equation on the observed execution, but does not claim
  the global counterfactual obtained by removing delay and replaying all later
  admission, queue, and thermal states. In 24MP mode, Lv0--4 comprise two MP24
  captures followed by MP12 captures, whereas Lv5--6 use the production MP12
  fallback; each decision uses its capture's actual executed resolution.
