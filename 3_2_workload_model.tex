\subsection{Workload Model and Shared Point Estimation}
\label{sec:model}
\input{figures/alg_point_estimation.tex}
Both control modules require estimates of remaining draft work.
Draft processing time varies with resolution, memory pressure, stage configuration, and thermal state (Section~\ref{sec:guard-limit}), which neither per-model timing tables nor the thermal level alone can capture.
The controller therefore estimates stage durations online from completed draft sequences with a point estimator that both modules share (Algorithm~\ref{alg:point-estimation}).

\smallskip\noindent\textbf{Workload key and sequence.}
For estimation, each processing stage and its configuration are identified by a workload key \(k\).
Capture \(i\)'s draft sequence is represented as a workload sequence of these keys in execution order, \(\mathcal{K}_i=(k_1,\ldots,k_m)\).
From key \(k_j\) onward, the remaining sequence is \(\mathcal{K}_{i,j}=(k_j,\ldots,k_m)\).
The last key \(k_m\) covers mandatory processing from encoding start through draft image saving, so estimates include the time needed to produce the draft image.

\smallskip\noindent\textbf{Point estimate.}
Algorithm~\ref{alg:point-estimation} computes the point estimate (\(\hat P\)) of a workload sequence (\(\mathcal K\)).
The algorithm models a stage's duration as a key-specific base duration \(\hat b(k)\) scaled by a factor \(\gamma\) shared across keys.
The base duration captures timing differences among stages and configurations, while \(\gamma\) provides a shared adjustment for changes in runtime conditions.
Initially, every base duration is zero and \(\gamma\) is one (line~\ref{alg:pe:init}).
\textsc{ComputePointEstimate} (lines~\ref{alg:pe:compute-first}--\ref{alg:pe:compute-last}) returns the sum of the predicted durations:
\begin{equation}
  \hat P(\mathcal{K})
  =\sum_{k\in\mathcal{K}}\hat p(k),
  \qquad
  \hat p(k)=\hat b(k)\,\gamma .
  \label{eq:point-estimate}
\end{equation}

\smallskip\noindent\textbf{Point-estimator update.}
At draft sequence completion, \textsc{UpdatePointEstimator} (lines~\ref{alg:pe:ratios}--\ref{alg:pe:condition}) uses measured stage durations (\(p\)) to update the estimator.
It divides each duration \(p(k)\) by the previous \(\gamma\) to put it on the base-duration scale.
It then incorporates the result into the key's cumulative average \(\hat b(k)\), which also reflects the key's earlier processing times.
If any of these keys ran before, it sets \(\gamma\) to the median ratio of the current durations to the previous base durations for those keys.
This lets predictions reflect recent runtime changes, while the median limits the effect of isolated stage slowdowns.
