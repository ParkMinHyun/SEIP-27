\subsection{Shared Predictor}
\label{sec:model}
The \emph{shared predictor} in Algorithm~\ref{alg:overview} provides the stage-duration estimates that both admission and pacing use.
Because draft processing time varies with stage configuration and runtime conditions (Section~\ref{sec:guard-limit}), the predictor updates these estimates online from completed draft sequences.
Admission applies them to the remaining sequence \(\mathcal K_{i,j}\), while pacing uses them to predict queued and upcoming draft work.

\smallskip\noindent\textbf{Point estimate.}
The point estimate \(\hat P(\mathcal K)\) of a workload sequence is the sum of its predicted stage durations.
Each predicted stage duration \(\hat p(k)\) is a key-specific base duration \(\hat b(k)\) scaled by a factor \(\gamma\) shared across keys:
\begin{equation}
  \hat P(\mathcal{K})
  =\sum_{k\in\mathcal{K}}\hat p(k),
  \qquad
  \hat p(k)=\hat b(k)\,\gamma .
  \label{eq:point-estimate}
\end{equation}
The base duration captures timing differences among stages and configurations, while \(\gamma\) provides a shared adjustment for changes in runtime conditions.
Initially, every base duration is zero and \(\gamma\) is one.

\smallskip\noindent\textbf{Online update.}
The predictor updates the key-specific base durations \(\hat b(k)\) and the shared factor \(\gamma\) separately after each draft sequence.
At draft completion, \(\mathit{predictor}.\textsc{ObserveDuration}\) (Algorithm~\ref{alg:overview}, line~\ref{alg:ov:update}) receives the measured durations \(p_i(k)\) of the stages executed in capture \(i\).
For each measured key that was observed in an earlier draft sequence, the predictor first computes \(p_i(k)/\hat b(k)\) from the base duration held before this update.
This ratio is the scale factor that would make that base duration match the current measurement.
It then divides each measured duration by the value of \(\gamma\) held before this update, so that the base duration does not double-count the runtime variation already represented by \(\gamma\).
The resulting \(p_i(k)/\gamma\) is incorporated into that key's cumulative average \(\hat b(k)\).
Finally, it replaces \(\gamma\) with the median of the \(p_i(k)/\hat b(k)\) ratios from the completed draft sequence.
If no ratio is available, \(\gamma\) remains unchanged.
The cumulative average dampens isolated spikes in a key's duration history.
When multiple ratios are available, their median reduces the influence of a deviation confined to one stage.
