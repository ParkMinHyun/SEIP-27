\subsection{Shared Predictor}
\label{sec:model}
Draft processing time varies with stage configuration and runtime conditions (Section~\ref{sec:guard-limit}).
To account for this variation, the shared predictor in Algorithm~\ref{alg:overview} estimates stage durations online from completed draft sequences.
Admission uses these estimates for the remaining sequence \(\mathcal K_{i,j}\), while pacing uses them to predict queued and upcoming draft work.

\smallskip\noindent\textbf{Point estimate.}
For a workload key \(k\) defined in Section~\ref{sec:objective}, the predictor models the stage's duration as a key-specific base duration \(\hat b(k)\) scaled by a factor \(\gamma\) shared across keys.
The base duration captures timing differences among stages and configurations, while \(\gamma\) provides a shared adjustment for changes in runtime conditions.
Initially, every base duration is zero and \(\gamma\) is one.
The point estimate \(\hat P(\mathcal K)\) of a workload sequence is the sum of its predicted stage durations:
\begin{equation}
  \hat P(\mathcal{K})
  =\sum_{k\in\mathcal{K}}\hat p(k),
  \qquad
  \hat p(k)=\hat b(k)\,\gamma .
  \label{eq:point-estimate}
\end{equation}

\smallskip\noindent\textbf{Update.}
At draft completion, \(\mathit{predictor}.\textsc{Update}\) (Algorithm~\ref{alg:overview}, line~\ref{alg:ov:update}) uses the measured durations \(p_i(k)\) of stages executed in capture \(i\) to update the per-key base durations \(\hat b(k)\) and the shared runtime factor \(\gamma\).
To estimate the runtime factor, it first compares measurements with their keys' previous base durations, recording \(p_i(k)/\hat b(k)\) only for keys with prior timing measurements.
It then normalizes each measured duration by the previous shared factor \(\gamma\), incorporating \(p_i(k)/\gamma\) into that key's cumulative average \(\hat b(k)\).
Finally, it sets \(\gamma\) to the median of the recorded ratios; if no ratios exist, \(\gamma\) remains unchanged.
The cumulative averages retain each key's timing history, while the shared factor reflects recent runtime changes and the median limits the influence of isolated slowdowns.
The measured draft sequence duration \(C_i\) contributes to the history used for pacing's duration reserve (Section~\ref{sec:pacing}).
