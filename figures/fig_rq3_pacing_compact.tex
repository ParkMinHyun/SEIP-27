% RQ3 companion figure: every mandatory-floor miss named in
% Table~\ref{tab:rq3_pacing_compact}, plotted so that the panel accounts for the
% deadline margin each capture kept instead of only measuring it.  The original
% RQ3 policy, selectivity and calibration figures remain untouched as historical
% alternatives; docs/rq3-current.md is the authoritative handoff for this pair.
%
% Source: data/rq3/coordination/floor_miss_{filter,encoding}.csv, split by what
% admission left running.  Regenerate with scripts/rq3_coordination_metrics.py
% then scripts/rq3_coordination_audit.py.
%
% Naming follows tables/tab_rq3_pacing_compact.tex, whose header carries the map
% between the printed terms and the column names the generated CSVs still use
% (pacing decision = transition, run = burst, missing delay = the CSVs'
% shortfall_ms, skipped optional work = demotion, deadline margin = realized
% margin).  Only the printed labels change; the CSV column names do not.
%
% ---------------------------------------------------------------------------
% Why the figure is this and not an aggregate, and why it is a scatter
% ---------------------------------------------------------------------------
% Earlier revisions spent the figure on the aggregates -- activation by budget
% band, a mechanism flow chart, a stacked partition of the required delay, a
% ladder of every decision that required one.  All of them restated the table,
% and the table can be cited.  The division of labour here is the one RQ2 already
% uses: the table carries the result and the figure takes the handful of
% exceptions the table names and shows what happened in them.  RQ3's exception
% set is the 14 pacing decisions that fell below the mandatory floor, the only
% place the controller failed a sufficient condition reconstructed after the run.
%
% The form, however, is deliberately NOT RQ2's.  A first attempt drew these 14
% cases as horizontal grouped bars with a right-hand text column, which is
% Figure~\ref{fig:rq2_unsafe_spike_anatomy} line for line; two figures in one
% paper that share a skeleton are read as the same exhibit twice.  This paper
% already spends a box diagram on the pipeline, grouped horizontal bars on RQ2,
% and a capture-index time series on the case study, so the one grammar left free
% is a scatter -- and it happens to be the right one, because the claim IS a
% comparison between two commensurable quantities and a scatter can put that
% comparison on the diagonal instead of asking the reader to compare bar lengths.
%
% ---------------------------------------------------------------------------
% Why THESE two axes: the diagonal has to be the deadline
% ---------------------------------------------------------------------------
% An earlier revision plotted the missing delay against the margin the capture
% kept.  It answered "how close was it" and nothing else: its diagonal marked
% "margin equalled the missing delay", which is not a boundary of anything, so a
% reader could see that the misses were survivable but never why.  Two of the 14
% sat below that line and the figure had to shade a region to explain that this
% was not a failure -- a figure arguing against its own geometry.
%
% Substituting the floor's own definition, 2*d_mand = B + 2*C_mand - T, into
% margin = (deadline - decision) - wait - C_exec turns the margin into an
% identity over three separately measured terms:
%
%   margin = [ deadline_ref + horizon_reserve + backlog_residual ] - 2*d_mand
%
%   deadline_ref      the controller prices the remaining window from the
%                     queue's binding deadline -- backlogDeadlineMs, "the
%                     deadline of whatever entered the backlog last, which is
%                     the one the whole queue has to fit inside"
%                     (CaptureAvailablePacingSession.kt, timeToDeadlineMsAt).
%                     This is the budget between that deadline and the capture's
%                     own timeout timestamp, which the floor never counted:
%                     0 to 1,323 ms here, P50 845 ms.
%   horizon_reserve   2*C_mand - C_exec.  The 2C horizon reserves a second Draft
%                     for the next capture, while this capture's own deadline
%                     has to cover only its own: 56 to 1,109 ms, P50 629 ms.
%   backlog_residual  B - wait, how well the measured backlog predicted the wait
%                     the capture actually served: -92 to -14 ms.  Near zero,
%                     which is itself the result -- the backlog clock is not
%                     where the margin came from.
%
% Splitting 2*d_mand into the part the delay applied and the part it did not
% gives the two axes, both in budget rather than in delay because one
% millisecond of waiting buys two of budget (it drains one from the backlog and
% moves the next deadline by one):
%
%   x = 2*(d_mand - d)                                the miss, as budget
%   y = deadline_ref + horizon_reserve + backlog_residual - 2*d
%
% so y - x is the realized margin exactly.  The diagonal is therefore margin = 0
% -- the deadline itself -- the vertical distance from a mark to it is that
% capture's margin, and the shaded half below it is where a capture misses its
% deadline.  scripts/rq3_coordination_audit.py asserts the identity closes on
% every analyzed decision, not only these 14; it does, to 1.0 ms, which is the
% two ceilings in the floor formulas.
%
% This is arithmetic on the realized trace, NOT a counterfactual.  It accounts
% for the margin that was observed; it says nothing about the margin a different
% delay would have produced, and the closed-loop objection in
% docs/rq3-current.md still forbids that claim.  Nor is the mark shape -- what
% admission left running -- the cause of the margin: d*_mand already excludes
% optional work, so skipping it documents coordination rather than closing the
% deficit.
%
% Units.  Shares of the Capture Timeout budget, never milliseconds.  The budget
% is an internal constant and an axis in ms would make it recoverable from any
% quantity the manuscript also prints as a share of it.  The generator emits both
% columns; the ms ones stay for the audit trail.
%
% Encoding.  Mark shape is what admission left running, which is the coordination
% dimension and varies: the single-frame optional stage S survived on 6 cases and
% only the mandatory work ran on 8.  Run identity is NOT encoded: the 14 cases
% fall in four runs but they do not cluster in this space, so a four-way mark
% would spend the figure's only free channel on something the reader cannot use.
% The per-run count is in the table.  Two cases carry labels -- the largest miss
% and the smallest margin -- because those are the two a reader will want to look
% up; "c" is the capture index within the run, the CSV's shot field.
%
% Frame.  Square, both axes 0 to 28% of the budget, so the diagonal is at 45
% degrees and "above the line" is a fair visual comparison rather than an
% artefact of aspect.  x only reaches 18.7%, so the lower right is empty by
% construction; that is where the legend and the annotations go.
