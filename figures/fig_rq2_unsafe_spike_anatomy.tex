%   A = 48U_metrics_12MP_normal_0729_PacingOnly_1.xlsx

%
%   id  book  runId  shot     B     Cbar      C      UB   C/Cbar  overrun
%   M1    A     30     21   1516    861.7   2033   903.8   2.36      517
%   M2    A     11      9   1308   1123.7   2367  1229.1   2.11     1059

%   M5    C     18     20    844    684.7    855   765.1   1.25       11
%   S1    C      6     11    975    625.7    979   915.0   1.56        4
%   S2    B     29     14    653    544.0    713   593.0   1.31       60
%   S3    C     18     20    472    397.3    483   467.7   1.22       11
%
% Panel (b) decomposition.  PostExecutionMetrics reports, per node,
% cpuTimeMs and cpuUtilizationRatio = cpuTimeMs / (wallTimeMs * cores);
% the device reports 8 cores, which the recorded triples confirm.  Summing
% over the remaining nodes gives wall = cpu / (util * cores) exactly, so
%   wall_e - wall_b = (cpu_e - cpu_b)/(util_b * cores)      <- CPU-time growth
%                   + cpu_e/(cores) * (1/util_e - 1/util_b) <- utilization loss
% Values (ms), CPU-time growth / utilization loss / total:
%   M1  372 /  799 / 1171     M5  181 /   -9 /  172
%   M2  380 /  854 / 1235     S1   34 /  321 /  354
%   M3  581 /  579 / 1159     S2  284 / -122 /  162
%   M4   59 /  107 /  167     S3  101 /  -15 /   87
% CPU-time factor 1.05-1.53x; utilization factor 0.60-1.18x.
% Blocking GC time was 0 ms in every baseline and every event; overheat level
% and thermal status were identical to the recent-safe baseline in all eight.

% Final compact layout: both panels share one row and panel (b) uses the
% reviewer-oriented, order-dependent accounting terminology.
