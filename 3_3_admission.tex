\subsection{Remaining-Sequence Admission}
\label{sec:admission}
\input{figures/alg_admission.tex}

\emph{Remaining-Sequence Admission} tests each optional stage immediately before execution, comparing an upper estimate of the entire remaining sequence's processing time with the budget still available.
Algorithm~\ref{alg:admission} returns \textsc{admit} or \textsc{skip} for the remaining sequence \(\mathcal K_{i,j}\), given \(T_{i,j}\), the time left until capture \(i\)'s Capture Timeout deadline.
The controller treats \(M\) and \(S\) as separate admission groups and immediately skips stage \(k_j\) if its group \(g(k_j)\) is in \(\mathcal D\) (line~\ref{alg:ad:skip}).

\smallskip\noindent\textbf{Estimation.}
At lines~\ref{alg:ad:estimate}--\ref{alg:ad:upper}, Algorithm~\ref{alg:admission} estimates how long the remaining sequence may take.
It starts from the point estimate \(\hat P(\mathcal K_{i,j})\) (line~\ref{alg:ad:estimate}), computed by the shared predictor.
Because stages can run longer than predicted, it scales \(\hat P\) by a residual factor derived from recent stage overruns (line~\ref{alg:ad:upper}).
The \textsf{SelectResidualFactor} function (line~\ref{alg:ad:select}) selects \(\phi_\tau(\mathcal K_{i,j})\) as the weighted \(\tau\)-quantile of recent residual samples.
It determines \(\tau\) from the Kish effective sample size \(n_{\mathrm{eff}}\) of the selected residual samples with weights \(w_l\)~\cite{kish-survey-sampling}:
\[
  n_{\mathrm{eff}}
  =\frac{(\sum_l w_l)^2}{\sum_l w_l^2},
  \qquad
  \tau=\frac{n_{\mathrm{eff}}}{n_{\mathrm{eff}}+1}.
\]
The selector is motivated by the expected CDF position \(n/(n+1)\) of the maximum of \(n\) i.i.d. continuous samples~\cite{david-order-statistics}, with \(n_{\mathrm{eff}}\) substituting for the sample count.
As the effective sample size grows, the selected quantile moves further into the observed upper tail.
The selector avoids a separately tuned target percentile, while the recency weighting applied at completion reduces the influence of older observations.
The resulting upper estimate is
\begin{equation}
  U(\mathcal{K})
  =\hat P(\mathcal{K})\,\phi_{\tau}(\mathcal{K}).
  \label{eq:upper-estimate}
\end{equation}

\smallskip\noindent\textbf{Decision.}
The controller admits an optional stage in an enabled group when the upper estimate fits within the remaining timeout budget, with a cold-start exception (line~\ref{alg:ad:decide}):
\begin{equation}
  U(\mathcal{K}_{i,j})\leq T_{i,j}
  \quad\text{or}\quad
  \hat P(\mathcal{K}_{i,j})=0.
  \label{eq:admission}
\end{equation}
This cold-start case \(\hat P(\mathcal{K}_{i,j})=0\) permits execution to obtain initial duration measurements.
The configured draft-stage sequence remains unchanged during continuous capture and can change only after all draft sequences in the queue have completed.
The first capture under a new configuration therefore starts with a fresh timeout budget.
If neither condition holds, the controller skips the stage and disables its group until the queue drains (lines~\ref{alg:ad:disable}--\ref{alg:ad:reject}), removing the group's stages from subsequent remaining sequences.
Keeping a group disabled prevents its visual effects from appearing and disappearing across consecutive draft images.

\smallskip\noindent\textbf{Calibration.}
At draft sequence completion, admission updates its residual histories using the completed sequence's measured stage durations \(p_i(k)\) (lines~\ref{alg:ad:measured}--\ref{alg:ad:histories}).
Since skipped stages have no measured durations, admission excludes them from each remaining sequence \(\mathcal K_{i,j}\), yielding a measured sequence \(\mathcal K\) (line~\ref{alg:ad:measured}).
Admission compares these measurements with the predictions \(\hat p(k)\) it retained before execution.
If any of these stages ran in an earlier draft sequence, the residual factor is
\begin{equation}
  \phi(\mathcal{K})
  =\frac{\sum_{k\in\mathcal{K}}\max\{\hat p(k),p(k)\}}
         {\sum_{k\in\mathcal{K}}\hat p(k)}.
  \label{eq:residual-factor}
\end{equation}
The per-key maximum preserves each stage's overrun even when another stage finishes faster than predicted.

When a completion yields residual factors, the controller decays the existing residual weights (line~\ref{alg:ad:histories}).
It then inserts one factor per distinct measured sequence into the corresponding history, each with unit weight.
Finally, we use a weight decay of \(0.90\), chosen at the knee of the tradeoff between overrun rate and the size of \(U\).

\smallskip\noindent\textbf{Watchdog fallback.}
An admitted stage may still run longer than predicted, and it cannot be cancelled once it enters native image processing.
The watchdog therefore limits how long the draft sequence waits for that stage:
\begin{equation}
  W_{i,j}=\max\{0,T_{i,j}-U(\mathcal{K}_{i,m})\},
  \label{eq:watchdog}
\end{equation}
where \(\mathcal{K}_{i,m}=(k_m)\), so \(U(\mathcal K_{i,m})\) reserves time for mandatory encoding and saving.
If the watchdog expires, the draft pipeline falls back to encoding and saving the preserved original input.
Until the queue drains, queued draft sequences take the same fallback, so the backlog clears without cascading timeouts.
