\subsection{Remaining-Sequence Admission}
\label{sec:admission}

Admission runs immediately before each optional stage, inline on the Draft critical path.
It calibrates \(\hat P\) with residual evidence to form \(U\), then compares \(U\) with the capture's live budget to admit or skip the stage.

\smallskip\noindent\textbf{Residual-calibrated upper estimate.}
The point estimate \(\hat P\) does not account for the upper-tail overruns driven by variation in on-device runtime conditions and image content.
The controller therefore learns a high-side correction from observed residuals rather than hand-tuning additive margins for individual devices and stages.
For each admission decision, the controller records the per-key predictions \(\hat p(k)\) for the corresponding remaining sequence \(\mathcal K\).
When the Draft Sequence completes, the controller compares those predictions with the realized durations \(p(k)\).
A recorded \(\mathcal K\) contributes a residual factor only if \(\hat P(\mathcal K)>0\) and \(p(k)>0\) for all \(k\in\mathcal K\):
\begin{equation}
  \phi(\mathcal{K})
  =\frac{\sum_{k\in\mathcal{K}}\max\{\hat p(k),p(k)\}}
         {\sum_{k\in\mathcal{K}}\hat p(k)}.
  \label{eq:residual-factor}
\end{equation}
A skipped stage therefore excludes only the recorded sequences containing that stage.
The per-key maximum prevents a faster-than-estimated stage from cancelling another stage's overrun and thus ensures \(\phi(\mathcal{K})\geq1\). 
Normalizing by the predicted sum over the same stages makes the factor comparable across duration scales.
When a completion yields factors, the controller first multiplies all existing weights in the sequence histories and cross-sequence pool by the same \(0.90\), then inserts each resulting factor into its corresponding sequence history and the pool with unit weight.
The controller selects the weighted \(\tau\)-quantile from the sequence's own factor history when available, and from the cross-sequence pool otherwise, and uses \(\phi_\tau(\mathcal K)=1\) if neither contains a factor.
It determines \(\tau\) from the Kish effective sample size \(n_{\mathrm{eff}}\) of the current weights \(w_l\) in the selected factor~\cite{kish-survey-sampling}:
\[
  n_{\mathrm{eff}}
  =\frac{(\sum_l w_l)^2}{\sum_l w_l^2},
  \qquad
  \tau=\frac{n_{\mathrm{eff}}}{n_{\mathrm{eff}}+1}.
\]
The choice \(\tau=n_{\mathrm{eff}}/(n_{\mathrm{eff}}+1)\) is motivated by the expected CDF position \(n/(n+1)\) of the maximum of \(n\) i.i.d. continuous samples~\cite{david-order-statistics}, with \(n_{\mathrm{eff}}\) substituting for the sample count. As \(n_{\mathrm{eff}}\) grows, the selected quantile moves further into the upper tail (e.g., \(\tau=0.91\) for \(n_{\mathrm{eff}}=10\)); downweighting older factors allows this degree of conservatism to adapt without a separately tuned target percentile.
Applying the selected factor \(\phi_\tau(\mathcal K)\) to \(\hat P(\mathcal K)\) yields \(U(\mathcal K)\), an empirical high-side estimate of the modeled remaining time for \(\mathcal K\):
\begin{equation}
  U(\mathcal{K})
  =\hat P(\mathcal{K})\,\phi_{\tau}(\mathcal{K}).
  \label{eq:upper-estimate}
\end{equation}

\smallskip\noindent\textbf{Live-budget admission.}
At admission point \(j\), \(T_{i,j}\) denotes the time remaining until the Capture Timeout deadline for capture \(i\).
The controller admits the optional stage exactly when
\begin{equation}
  U(\mathcal{K}_{i,j})\leq T_{i,j}
  \quad\text{or}\quad
  \hat P(\mathcal{K}_{i,j})=0.
  \label{eq:admission}
\end{equation}
When \(\hat P(\mathcal K_{i,j})=0\), the controller admits the stage to bootstrap subsequent estimates; during validation, any Capture Timeout observed in this case constitutes a release blocker.
Once admission rejects an \(M\) or \(S\) stage, the optional stages in that group are removed from subsequent remaining sequences until the queue drains. The two groups are tracked independently, so a rejection in one does not disable the other; this sticky demotion prevents optional effects from alternating across consecutive captures while preserving timeout headroom.

\smallskip\noindent\textbf{Watchdog fallback.}
Admission cannot fully anticipate post-admission slowdowns. The watchdog therefore limits each admitted optional stage's execution time to \(W_{i,j}\):
\begin{equation}
  W_{i,j}=\max\{0,T_{i,j}-U(\mathcal{E}_i)\},
  \label{eq:watchdog}
\end{equation}
where \(\mathcal{E}_i\) contains only the mandatory terminal work from encoding through Draft image saving; subtracting \(U(\mathcal E_i)\) reserves time for that work before the deadline.
If the watchdog expires, the current Draft Sequence falls back to encoding and saving from a preserved copy of the original input. 
Already queued Draft Sequences likewise follow the same fallback path until the queue drains.
