\subsection{Remaining-Sequence Admission}
\label{sec:admission}

A capture's remaining timeout budget decreases while it waits for the draft worker and executes earlier stages.
\emph{Remaining-Sequence Admission} therefore runs immediately before each optional stage and compares the estimated duration of the entire remaining sequence, including mandatory encoding and saving, with the remaining timeout budget.

\smallskip\noindent\textbf{Admission rule.}
The controller tracks \(M\) and \(S\) as separate admission groups.
At admission point \(j\), let \(T_{i,j}\) be capture \(i\)'s remaining timeout budget, the time left until its Capture Timeout deadline.
Let \(U(\mathcal K_{i,j})\) be an empirical upper estimate of its remaining processing time, obtained by correcting \(\hat P\) with observed prediction errors as described below.
An optional stage in an enabled group is admitted when
\begin{equation}
  U(\mathcal{K}_{i,j})\leq T_{i,j}
  \quad\text{or}\quad
  \hat P(\mathcal{K}_{i,j})=0.
  \label{eq:admission}
\end{equation}
A zero point estimate permits execution to obtain the initial duration observations needed by the model.
This cold-start decision has no prior timing evidence; any Capture Timeout observed during its validation remains a release blocker.

Once an \(M\) or \(S\) stage is rejected, the controller disables that group until the queue drains: it skips the group's stages and removes them from subsequent remaining sequences.
The two groups are tracked independently, so rejecting one does not disable the other.
Keeping a group disabled until the drain prevents its processing from appearing and disappearing across consecutive draft images.

\smallskip\noindent\textbf{Residual-calibrated upper estimate.}
The point estimate \(\hat P\) can understate processing time when runtime conditions or image content cause a stage to run longer than predicted.
The controller computes a multiplicative correction from observed prediction errors to account for these overruns without separate additive margins for each device or stage.
For each admission decision, the controller records the per-key predictions \(\hat p(k)\) for the corresponding remaining sequence.
At draft sequence completion, it retains the keys with positive measured durations \(p(k)\) from each recorded remaining sequence to form a measured sequence \(\mathcal K\).
If their total predicted duration is positive, the residual factor is
\begin{equation}
  \phi(\mathcal{K})
  =\frac{\sum_{k\in\mathcal{K}}\max\{\hat p(k),p(k)\}}
         {\sum_{k\in\mathcal{K}}\hat p(k)}.
  \label{eq:residual-factor}
\end{equation}
The per-key maximum preserves each stage's overrun even when another stage finishes faster than predicted, ensuring \(\phi(\mathcal{K})\geq1\).
Normalizing by the predicted duration makes the factor comparable across sequences.

When a completion yields factors, the controller multiplies the existing weights in all sequence histories and the cross-sequence pool by \(0.90\).
It then inserts one factor per distinct measured sequence into the corresponding history and the pool, each with unit weight.
To calibrate a remaining sequence, it selects the weighted \(\tau\)-quantile from that sequence's history.
If the history is empty, it uses the pool; if both are empty, it sets \(\phi_\tau(\mathcal K)=1\).
It determines \(\tau\) from the Kish effective sample size \(n_{\mathrm{eff}}\) of the current weights \(w_l\) in the selected history~\cite{kish-survey-sampling}:
\[
  n_{\mathrm{eff}}
  =\frac{(\sum_l w_l)^2}{\sum_l w_l^2},
  \qquad
  \tau=\frac{n_{\mathrm{eff}}}{n_{\mathrm{eff}}+1}.
\]
The selector is motivated by the expected CDF position \(n/(n+1)\) of the maximum of \(n\) i.i.d. continuous samples~\cite{david-order-statistics}, with \(n_{\mathrm{eff}}\) substituting for the sample count.
As the effective sample size grows, the selected quantile moves further into the observed upper tail.
The selector avoids a separately tuned target percentile, while recency weighting reduces the influence of older observations.
Applying the selected factor gives
\begin{equation}
  U(\mathcal{K})
  =\hat P(\mathcal{K})\,\phi_{\tau}(\mathcal{K}).
  \label{eq:upper-estimate}
\end{equation}
The resulting \(U\) is empirical; it provides neither a worst-case time bound nor a statistical coverage guarantee.

\smallskip\noindent\textbf{Watchdog fallback.}
An admitted stage may still run longer than predicted.
The watchdog therefore limits how long the draft sequence waits for that stage before starting fallback:
\begin{equation}
  W_{i,j}=\max\{0,T_{i,j}-U(\mathcal{E}_i)\},
  \label{eq:watchdog}
\end{equation}
where \(\mathcal{E}_i=(k_m)\) contains only the last key, the mandatory processing from encoding through draft image saving.
Subtracting \(U(\mathcal E_i)\) reserves its estimated duration within \(T_{i,j}\).
If the watchdog expires, the framework proceeds to encoding and saving from the preserved original input.
Already queued draft sequences follow the same fallback until the queue drains.
