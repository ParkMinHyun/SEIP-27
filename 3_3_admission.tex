\subsection{Remaining-Sequence Admission}
\label{sec:admission}

Admission runs immediately before each optional stage.
It derives a high-side estimate \(U\) of the remaining sequence from \(\hat P\) and learned residual evidence, then compares \(U\) with the capture's live timeout budget to admit or skip the stage.

\smallskip\noindent\textbf{Residual-calibrated upper estimate.}
The point estimate \(\hat P\) cannot fully capture upper-tail overruns driven by variation in on-device runtime conditions and image content.
The controller therefore learns a high-side correction from observed residuals rather than modeling these effects separately or hand-tuning additive margins for individual devices and stages.
The residual factor for a completed \(\mathcal{K}\) with \(\hat P(\mathcal{K})>0\) compares realized per-key durations \(p(k)\) against their decision-time predictions:
\begin{equation}
  \phi(\mathcal{K})
  =\frac{\sum_{k\in\mathcal{K}}\max\{\hat p(k),p(k)\}}
         {\hat P(\mathcal{K})}.
  \label{eq:residual-factor}
\end{equation}
The per-key maximum prevents a faster-than-estimated stage from cancelling another stage's overrun and ensures \(\phi(\mathcal K)\geq1\), while normalization by \(\hat P(\mathcal K)\) makes the factor comparable across duration scales.

The controller uses the exact-sequence factor history when available, falling back to a pooled history across sequences.
Each factor enters both histories with unit weight and follows the shared recency decay; let \(w_l\) denote the resulting weight of factor \(l\).
Given at least one factor in the selected history, the controller sets \(\tau\) from the Kish effective sample size \(n_{\mathrm{eff}}\)~\cite{kish-survey-sampling}:
\[
  n_{\mathrm{eff}}
  =\frac{(\sum_l w_l)^2}{\sum_l w_l^2},
  \qquad
  \tau=\frac{n_{\mathrm{eff}}}{n_{\mathrm{eff}}+1}.
\]
The controller sorts the factors in ascending order and sets \(\phi_{\tau}(\mathcal{K})\) to the first whose cumulative weight meets or exceeds \(\tau\sum_l w_l\); with no observed factor, it uses \(\phi_{\tau}(\mathcal{K})=1\).
The choice of \(\tau\) substitutes \(n_{\mathrm{eff}}\) for \(n\) in the order-statistic result that the maximum of \(n\) independent observations from a common continuous distribution has expected quantile position \(n/(n+1)\)~\cite{david-order-statistics}.
This substitution is an engineering heuristic for recency-weighted evidence: with equal weights, the selector returns the observed maximum, whereas recency decay allows sufficiently old extremes to lose influence.
This evidence-adaptive rule selects only observed factors and requires no separately tuned target percentile.
Applying the selected factor to \(\hat P\) yields \(U\), an empirical high-side estimate, not a formal timing bound:
\begin{equation}
  U(\mathcal{K})
  =\hat P(\mathcal{K})\,\phi_{\tau}(\mathcal{K}).
  \label{eq:upper-estimate}
\end{equation}

\smallskip\noindent\textbf{Live-budget admission.}
At admission point \(j\) of capture \(i\), the controller admits the optional stage when \(U\) fits the live budget \(R_{i,j}\), or when its remaining sequence is still unpriced, a fail-open that collects the missing observations:
\begin{equation}
  U(\mathcal{K}_{i,j})\leq R_{i,j}
  \quad\text{or}\quad
  \hat P(\mathcal{K}_{i,j})\leq0.
  \label{eq:admission}
\end{equation}

When the gate skips a stage, the controller adds its effect group to a queue-local set \(G\), tracking the groups containing \(M\) and \(S\) independently.
Until the Draft task queue drains and clears \(G\), later stages in that group are skipped in the current and subsequent Draft Sequences without reevaluating Equation~\ref{eq:admission}.
This sticky demotion prevents effect alternation across consecutive captures and preserves timeout headroom.

\smallskip\noindent\textbf{Watchdog fallback.}
Admission cannot fully anticipate sudden slowdowns after an optional stage begins, such as those caused by CPU scheduling contention, memory reclamation, or abrupt changes in image-processing performance.
The watchdog therefore assigns each admitted optional stage a budget \(W_{i,j}=\max\{0,R_{i,j}-U(\mathcal{E}_i)\}\), reserving \(U(\mathcal{E}_i)\) for the mandatory encoding-and-saving interval \(\mathcal{E}_i\).
On expiration, the Draft pipeline falls back to the original input for saving; the stage worker continue in parallel, but its output is discarded.
